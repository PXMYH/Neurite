Flow

Five things the diagram can’t show

Nothing is bundled. index.html has one script tag: js/main.js. The other 81 files are fetched in order by PageLoad.scripts as plain <script src> into one shared global scope.

A new file that isn’t in that array simply never runs. Position matters: anything touched at class-body level needs its dependency loaded earlier.

Positions are complex numbers. Node coordinates live in the Mandelbrot plane, not screen space. Graph.pan and Graph.zoom are vec2 complex values; every node’s step(dt) then adds a pull along Fractal.grad, so nodes drift toward set boundaries.

Text and graph are one loop, gated by flags. Typing rewrites nodes; dragging a node title rewrites the text. Three globals in globals.js — processAll, bypassZettelkasten, restoreZettelkastenEvent — are what stop that loop feeding itself.

Persistence is DOM-shaped. A node serializes into content.dataset.node_json, and re-hydration replays dataset.node_extras through Node.Extensions. A new widget without a push_extra_cb entry silently vanishes on reload.

The backend is optional and auto-detected. The app polls GET localhost:7070/check and flips one global, useProxy. That single boolean re-routes every AI call from “browser holds the key” to “server holds the key”.
