Nodes live inside the Mandelbrot set. Scroll to move through it, and the space you make is where new nodes go.

Move
Drag Move around the fractal.
Scroll Zoom. Zoom in before making nodes, so they have room to grow.
Esc Drop a node that is following the pointer.
Make a node
Shift + double-click Text node, on empty space.
Alt + double-click Ai node. Does nothing while Ai features are off.
Ctrl + double-click Link node, for a web page or a file.
1 2 3 4 The four tools in the bar at the top: note, link, edges, Ai. Drag one onto the canvas to choose where it lands, or press its number.
Drop a file Anywhere on the canvas. Text, image, audio, video and PDF each become the node type that fits.
Connect
Shift + click two nodes Join them with an edge.
Click an edge Turn the arrow: one way, the other way, then none. Release Shift first.
Shift + double-click an edge Delete it.
Shift + scroll an edge Change its length.
Select and arrange
Ctrl + click Select a node. Click it again to deselect, or click empty space to clear the whole selection.
Ctrl + drag the canvas Draw a box and select everything it touches.
← ↑ ↓ → Move the selection. Two at once move on the diagonal.
f / d Grow or shrink the selection.
Double-click a window Anchor it, so the fractal stops carrying it. Again releases it. Inside a text box, hold Alt as well.
Right-click a node Its own menu: delete, connect, extract text, zoom to, and more.
Drag a title bar Move one window. Shift + scroll over it resizes it.
Alt + drag or click Reach the node underneath a text box, instead of typing into it.
Write the graph as text
## Title Starts a node. The lines under it are its text. The Ai prompt in the Ai tab writes this for you; there is no editor to type it into.
[[Title]] An edge to the node with that title. Editing a node on the canvas rewrites this text, and the reverse, so the two are one thing.
Both tags Rebindable in Settings, under Zettelkasten.
Fractal lines
Alt + f Keep the lines on screen as the view moves.
Alt + c Release every kept line.
Alt + s Save the lines as a PNG file.
Fractal tab Line count, length, width and colour. Lower them if the view lags.
Ask the Ai about Neurite
Sends this app's own instructions with your next prompt, so the Ai can answer questions about Neurite. It replaces the notes it would otherwise have sent as context, so turn it off for ordinary work.

Shift, Alt and Control are defaults. Rebind them, and the mouse buttons, in the control settings.
