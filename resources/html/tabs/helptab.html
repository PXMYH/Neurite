Nodes live inside the Mandelbrot set. Scroll to move through it, and the space you make is where new nodes go.

Move
Drag Move around the fractal.
Scroll Zoom. Zoom in before making nodes, so they have room to grow.
Alt + scroll Turn the view about the pointer.
0 t Home + - Fit, Tidy and Home, the buttons at the bottom left, and zoom in and out. Fit takes the selection when there is one, and every note when not.
Esc Drop a node that is following the pointer, a link you started, and the selection, and turn the Connect tool off. An open menu or dialog takes it first, and so does a card you are typing in: the first press leaves it.
Make a node
Double-click Text node, on empty space, with the caret already in it.
Alt + double-click Ai node. Does nothing while Ai features are off.
Ctrl + double-click Link node, for a web page or a file.
1 2 3 4 The four tools in the bar at the top: note, link, file tree, Ai. Drag one onto the canvas to choose where it lands, or press its number.
Drop a file Anywhere on the canvas. Text, image, audio, video and PDF each become the node type that fits.
Connect
Shift + click two nodes Join them with an edge. Esc drops the first click if you change your mind.
The Connect tool The same without the key: click it in the bar at the top, then click pairs of nodes. It stays on until you click it again or press Esc.
+ link on a card Pick a node to join it to: the nearest are listed first, and typing narrows the list. Enter links the first one not linked yet; ↑ ↓ choose another. A node that is already joined is marked ✓, and clicking it again unlinks it.
Right-click an edge Turn the arrow: each turn moves it on to one way, the other way, or neither. An arrow points at the note that is named, so [[B]] written in A points at B, and a turn between two notes rewrites their [[Refs]]: one that would take a Ref out of a note asks first. A plain click on an edge does nothing.
Shift + double-click an edge Delete it, as a double-click does with the Connect tool on. So does the edge's right-click menu, or the × beside the link on either card. The [[Title]] that wrote it goes too.
Shift + scroll an edge Change its length.
Select and arrange
Ctrl + click Select a node. Click it again to deselect; click empty space or press Esc to clear the whole selection. The panel at the bottom left counts what is selected.
Ctrl + drag the canvas Draw a box and select everything it touches.
← ↑ ↓ → Move the selection. Two at once move on the diagonal.
f / d Grow or shrink the selection.
Double-click a window A note arrives pinned, and stays where you put it. Double-click releases it to the fractal, which carries it along; again pins it where it is. Inside a text box, hold Alt as well.
Right-click a node Its own menu: zoom to it, delete it, link it, and more. Click one to do it, or its pin to keep it at the top of the menu. Type to search them; Enter does the first.
Drag a title bar Move the window, and the rest of the selection with it when it is in one. Shift + scroll over it resizes it, or the whole selection.
Alt + drag or click Reach the node underneath a text box, instead of typing into it.
Write the graph as text
## Title Starts a node. The lines under it are its text. Type it in the menu's Notes panel, or let the Ai prompt in the Ai panel write it for you.
Esc in the notes Leave the Notes panel's editor. Tab types a tab there, so this is the way out by keyboard.
[[Title]] An edge to the node with that title. Editing a node on the canvas rewrites this text, and the reverse, so the two are one thing.
Archives Several texts for one graph, chosen at the top of the Notes panel; new notes go into the one shown. A title names one note in all of them: written a second time, it is marked and makes no second note.
Both tags Rebindable in Settings, under Zettelkasten.
Fractal lines
Alt + f Keep the lines on screen as the view moves.
Alt + c Release every kept line.
Fractal panel Line count, length, width and colour. Lower them if the view lags.
Ask the Ai about Neurite
Sends this app's own instructions with your next prompt, so the Ai can answer questions about Neurite. It replaces the notes it would otherwise have sent as context, so turn it off for ordinary work.

Shift, Alt and Control are defaults. Rebind them, and the mouse buttons, in the control settings. On a Mac, Command does what Control does here: Control and a click is the Mac's right-click. And Alt is the key marked Option.
